# @layer_ai/sdk

The official JavaScript and TypeScript SDK for [Layer](https://layer.ai), the AI platform for
creating game assets across image, video, 3D and audio.

```bash
npm install @layer_ai/sdk
```

- **Package:** [npmjs.com/package/@layer_ai/sdk](https://www.npmjs.com/package/@layer_ai/sdk)
- **Documentation:** [layer.ai/docs/sdk](https://layer.ai/docs/sdk)
- **REST API reference:** [layer.ai/docs](https://layer.ai/docs)
- **Support:** [help.layer.ai](https://help.layer.ai/)

The SDK is developed in Layer's main repository and published to npm from there. This repository
is its public home on GitHub; the published package carries the compiled source, type
declarations and README. Licensed under [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0).
